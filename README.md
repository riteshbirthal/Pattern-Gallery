# Pattern Gallery

An interactive catalog of **69 algorithmic pattern generators**. Each one is generated by a different mathematical mechanism — cellular automata, reaction-diffusion, fractal iteration, noise fields, chaos theory, parametric curves, aperiodic tilings, space-filling curves, maze generation, number-theoretic constructions, classical mechanics, oscillator networks, procedural synthesis — and ships with parameter sliders, a live canvas, and a math-typeset explainer.

Built as a static site with Vite + TypeScript + React. Renderers use Canvas2D and WebGL2; math is typeset with KaTeX.

## How to add a new pattern

Each pattern is a self-contained folder under `src/patterns/`. To add one:

1. Create `src/patterns/<id>/`.
2. Implement `renderer.ts` exporting a class that satisfies the `Renderer` interface (`init`, `step`, `draw`, `setParams`, `reset`, `dispose`).
3. Write `index.ts` exporting a `Pattern` object: id, title, category, blurb, params schema, and the renderer factory.
4. Write `Explainer.tsx` for the side panel.
5. Register the pattern in `src/patterns/registry.ts`.

The viewer auto-generates parameter controls from the schema. Drop in a folder, register it, and it appears in the gallery.

## Architecture

```
src/
  components/
    PatternViewer.tsx    canvas + params + explainer layout
    PatternThumbnail.tsx live mini-renderer for the gallery cards
    HeroBackground.tsx   animated flow-field hero background
    ParamControl.tsx     auto-generated sliders/selects
    Math.tsx             KaTeX wrapper
  patterns/
    registry.ts          central list + categories
    <pattern-id>/
      index.ts           Pattern metadata + params schema
      renderer.ts        Renderer implementation
      Explainer.tsx      math + explanation
  routes/
    Gallery.tsx          /
    PatternRoute.tsx     /pattern/:id
  types/
    pattern.ts           Renderer + Pattern interfaces
  test/                  vitest suites
```

## Tests

Vitest with jsdom. 85 tests across 6 suites:

- `registry.test.ts` — pattern integrity, unique ids, default values within param ranges
- `hex.test.ts` — hex grid neighbour math (parity, reciprocity, geometry)
- `snowflake.test.ts` — Reiter renderer init/step/dispose, seed correctness, growth
- `flowfield.test.ts` — particle count sync, off-canvas respawn
- `params.test.tsx` — `ParamControl` renders the right input type
- `canvas2d-patterns.test.ts` — smoke tests for all 62 Canvas2D patterns + Conway blinker oscillation + Rule 90 XOR transition

WebGL pieces (Gray-Scott, Mandelbrot, Julia, Newton, Burning Ship) are smoke-tested only via the registry — jsdom does not provide a real WebGL context.
